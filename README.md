## 🚀 Featured Projects

<details>
<summary><b>🧠 HEADSTART — Explainable AI Financial Research Platform</b></summary>
<br/>

An end-to-end, explainable AI-driven financial research and intelligence platform. A user selects a listed company and receives financial & market analytics, ML-based anomaly detection, NLP-driven document intelligence, event detection, and an explainable investment research score — plus an AI research assistant to query it all in natural language. Built solo, module by module, with real public market data only.

| | |
|---|---|
| **Stack** | Python · Pandas · NumPy · scikit-learn · PostgreSQL · SQLAlchemy · FastAPI · Streamlit |
| **Scale** | 10-table relational schema (companies, prices, statements, metrics, news, documents, NLP results, events, anomalies, research scores) |
| **Performance** | Isolation Forest + statistical baselines for real-time anomaly flagging on price/volume series |
| **Security** | Secrets managed via `.env` (excluded from version control); strict foreign-key integrity over polymorphic joins |
| **Impact** | Turns raw filings, prices, and news into a single explainable research score per company |
| **Repository** | [github.com/Shree0226/headstart](https://github.com/Shree0226/headstart) |

Every score the platform produces is designed to be traceable back to the underlying data — the goal is a research tool an analyst can actually trust, not a black box.

</details>
